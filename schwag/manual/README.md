# Super Dragon's Lair Arcade - User Manual

This directory contains the full instruction booklet for the SNES CD Edition of **Super Dragon's Lair Arcade** (MSU-1). Designed in the style of classic SNES-era instruction manuals.

## How to View

Open `usermanual-page000.md` (the cover) and follow the links to navigate through the manual. Each page includes thematic SVG artwork and in-game screenshots.

## Contents

### Front Matter
*   **Cover:** `usermanual-page000.md`
*   **Story & How to Play:** `usermanual-page001.md`
*   **Controls, Game Modes & Secrets:** `usermanual-page002.md` (D-pad, Sword, Flash system, Game Modes, Konami Code, Scene Select)

### Character Bios (9 profiles)
*   **Dirk the Daring:** `usermanual-bio-dirk.md` -- The hero. Clumsy but courageous.
*   **Princess Daphne:** `usermanual-bio-daphne.md` -- The fair maiden. Imprisoned in a crystal sphere.
*   **Singe the Dragon:** `usermanual-bio-singe.md` -- The final boss. Ancient, powerful, and furious.
*   **The Lizard King:** `usermanual-bio-lizardking.md` -- Singe's lieutenant. Guards the treasury.
*   **The Black Knight:** `usermanual-bio-blackknight.md` -- A phantom guardian on horseback.
*   **The Grim Reaper:** `usermanual-bio-grimreaper.md` -- The Shapeshifter. Lord of Thorns.
*   **The Smithee:** `usermanual-bio-smithee.md` -- A cursed blacksmith of living bronze.
*   **The Giddy Goons:** `usermanual-bio-giddygoons.md` -- Cackling purple ambush predators.
*   **The Mudmen:** `usermanual-bio-mudmen.md` -- Animated sludge that assimilates its prey.

### Scene Guide
*   **Quick Reference:** `usermanual-sceneguide.md` -- All 29 scenes at a glance with screenshots.
*   **Individual Scenes:** `usermanual-scene-001.md` through `usermanual-scene-029.md` -- Detailed page per scene with atmospheric descriptions, threats, actions, and tips.

### Castle Map
*   **Map Overview:** `usermanual-map.md` -- Mermaid diagram showing the castle's zones and room connections.

## Assets

All images are in the `images/` directory:
*   **Screenshots:** `.png` files -- in-game screenshots from each scene
*   **Theme Art:** `.svg` files -- decorative headers for each manual page, featuring thematic illustrations (dragon silhouettes, lightning, gold coins, castle towers, enchanted weapons, etc.)
